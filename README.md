### Sobre mí

Estudio **Ingeniería en Sistemas Computacionales** en la ESCOM del IPN (5.º semestre) y soy técnico en telecomunicaciones. Hago aplicaciones web con React, Next.js y Flask, y las despliego con Docker en un servidor Debian que administro yo.

Busco un puesto de becario o desarrollador junior.
